Եռանկյունաչափական արժեքներ և գրաֆիկներ

Այս էջում կան հիմնական և լրացուցիչ անկյունների արժեքները, քառորդների նշանները, միավոր շրջանը և sin, cos, tg, ctg ֆունկցիաների գրաֆիկները։

Հիմնական աղյուսակ Քառորդների նշաններ Լրացուցիչ անկյուններ Միավոր շրջան Գրաֆիկներ

Հարաբերությունctg α = x / y

Ֆունկցիաների գրաֆիկներ

Այստեղ x-ը անկյունն է ռադիաններով, իսկ y-ը ֆունկցիայի արժեքն է։ tg և ctg գրաֆիկներում կետագծերը այն տեղերն են, որտեղ ֆունկցիան որոշված չէ։

y = sin x

Սկսվում է 0-ից, π/2-ում դառնում է 1, π-ում նորից 0։

y = cos x

Սկսվում է 1-ից, π/2-ում դառնում է 0, π-ում՝ −1։

y = tg x

tg x = sin x / cos x, դրա համար չկա, երբ cos x = 0։

y = ctg x

ctg x = cos x / sin x, դրա համար չկա, երբ sin x = 0։

Ամենակարևոր կանոնները

Այս կանոնները թույլ են տալիս չսովորել բոլոր անկյունները առանձին։

1. Բերել հիմնական անկյանՕրինակ՝ 840° = 720° + 120°, հետևաբար sin840° = sin120°։
2. Քառորդի նշանըI-ում բոլորը + են, II-ում միայն sin, III-ում tg/ctg, IV-ում միայն cos։
3. Համալրող անկյուններsin(180° − α) = sin α, իսկ cos(180° − α) = −cos α։
4. Կիսանկյուններ22.5° = 45°/2, իսկ 15° = 45° − 30°։
